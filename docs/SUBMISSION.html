1. Problem Statement & Why ChapterChat Was Built

the Chapter Co. (thechapterco.in) crafts bespoke, hand-painted keepsake storybooks from real customer memories, family milestones, and wedding celebrations across India. Each book involves 2 to 4 weeks of high-touch, iterative collaboration between families and in-house illustrators:

  • Families submit dozens of intimate photos and memories.
  • Studio artists hand-sketch and paint multi-spread gouache layouts.
  • Clients review proofs, request revisions, and officially approve spreads before Japanese layflat archival binding.
The Operational Bottleneck: Historically, this took place over fragmented WhatsApp chats and email threads. High-resolution reference photos were lost in camera rolls, revision feedback was ambiguous ("Can you fix page 3?"), and sign-offs were scattered, creating costly production delays.

ChapterChat solves this by establishing a dedicated real-time collaboration harbor for every storybook order, uniting client families and studio illustrators in an elegant, structured workspace.

2. Nexconn Chat SDK Deep Integration

ChapterChat integrates 10+ core primitives of the Nexconn Communication Platform under App Key z3v5yqkbzet10:

1. Dynamic Token Authentication

Secure server-side HMAC-SHA1 signature generation requesting access tokens via POST /v4/auth/access-token/issue.

2. Dedicated Group Channels

Every storybook commission spins up an isolated room: tcc-tcc-{orderId} using GroupChannel and /v4/group-channel/create.

3. Real-Time Message Pipeline

Messages dispatched via SendTextMessageParams & channel.sendMessage(), caught in real-time by NCEngine.addMessageHandler().

4. Inline Spread Proofing Cards

Hand-painted watercolor spreads are delivered directly in the message stream with instant inspection modals.

5. Message Reactions & Feedback

Instant emotional and design feedback (❤️ Love it, 🔄 Needs tweak, 🎨 Color note) via the Nexconn reaction API.

6. One-Click Print Sign-Off

Clients click ✅ Approve for Print to broadcast official approval records and update studio print readiness counters.

7. ChapterBot AI Studio Copilot

Parses chat conversations into structured, prioritized action briefs for illustrators (Likeness, Lighting, Typography).

8. Production Milestone Tracking

Visual 5-step lifecycle tracking from Photo Intake to Character Sketching, Proofing, and Doorstep Dispatch.
